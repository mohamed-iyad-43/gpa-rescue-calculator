# GPA Calculator with Details
A simple Python script designed to compute the overall GPA and Calculate the minimum score required to pass in academic systems based on a 20-pt scale.


---

## Features
- **Calculates your overall GPA as well as the passing average.
- **Operates strictly within the specified range from 0 to 20.
- **Simple and user-friendly command-line prompts.

## Getting Started
### Prerequisites 
* Python 3.8.2
### How to run 
```bash
python main.py
```
